# France Hiring Signals — HelloWork

Turn French job postings into company-level hiring signals.

## Status: investigation blocked — no Actor implemented

The pre-development investigation on 2026-09-25 found a conflict between the requested arbitrary-keyword search workflow and HelloWork's published robots.txt rules. The project instructions explicitly require avoiding disallowed paths. Development therefore stopped before implementing or testing an Actor.

This repository is an investigation record, not a working MVP or an Apify-ready product. See [the investigation report](investigation/REPORT.md) and the captured [robots.txt](investigation/robots.txt).

The intended product measures observed hiring activity, not company growth, financial health, purchasing intent, or commercial qualification.

No paid events, scraping runtime, browser, proxy, API integration, or candidate-data collection have been implemented.
